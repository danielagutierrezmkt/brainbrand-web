# Skill: Esencia de Marca

Esta es una skill para Claude que te guía—una pregunta a la vez—para definir la
**Esencia de tu marca** y te entrega un documento listo para usar.

## Cómo instalarla

**En Claude (claude.ai) con Skills:**
1. Descomprime esta carpeta.
2. Sube la carpeta `esencia-de-marca-skill` (que contiene `SKILL.md`) como skill.
3. Inicia una conversación y di: *"Ayúdame con mi esencia de marca"*.

**En Claude Code:**
1. Copia la carpeta `esencia-de-marca-skill` dentro de `.claude/skills/` de tu proyecto.
2. Invócala con `/esencia-de-marca`.

## ¿No usas Claude?
No pasa nada. En la página de entrega tienes el **prompt universal**: cópialo y
pégalo en ChatGPT o Claude y funciona igual.
